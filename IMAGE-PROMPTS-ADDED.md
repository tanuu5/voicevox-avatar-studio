# 追加キャラクターの画像生成

組み込みimage_genツールを使いました。公式サイトの画像を外見の参照、既存のずんだもんを画風・配置の参照として、新しい非公式のスプライトシートを生成しています。アプリで使用する画像は public/assets/metan.png、tsumugi.png、kiritan.png です。
